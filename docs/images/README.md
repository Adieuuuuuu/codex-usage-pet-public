  rendered from the real Usage Pet renderer with fully synthetic task data and
  cropped to the product surface; CC BY 4.0.
- `android-companion-production.png`: API 36 emulator capture of Android

  applied; CC BY 4.0.

device token, prompt body, response body, or real task title. They document one
implementation moment and do not replace physical-device acceptance.
